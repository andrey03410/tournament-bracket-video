# OST Top Builder — MVP

Веб-приложение: строит **топы саундтреков (OST) и видео** методом попарных
сравнений (турнирная сетка), затем рендерит видео-«топ». Треки могут быть аудио
и/или видео (смешанные турниры поддерживаются). Для авторизованных пользователей,
с сохранением турниров и видео в личном кабинете.

Спецификации и план — в [`.ai/`](.ai/). Видение: [`.ai/specs/00-vision.md`](.ai/specs/00-vision.md).

## Стек

- **Next.js 14** (App Router, React 18) — фронт + API.
- **Prisma + SQLite** (MVP; продакшн-таргет Postgres — смена `provider` в схеме).
- **Auth.js (next-auth v5)** — email + пароль.
- **Remotion** — рендер видео (16:9, 1080p).
- **ffmpeg-static** — декод/нарезка аудио, RMS-анализ активного сниппета.
- **Vitest** — тесты.

## Быстрый старт

```bash
npm install
cp .env.example .env          # при необходимости отредактируйте AUTH_SECRET
npx prisma generate
npx prisma db push            # создаёт SQLite-схему (prisma/dev.db)
npm run dev                   # http://localhost:3000
```

Для рендера видео (один раз, в окружении с доступом в сеть):

```bash
npx remotion browser ensure   # скачивает chrome-headless-shell
# или укажите путь к chrome-headless-shell:
# REMOTION_BROWSER_EXECUTABLE=/path/to/chrome-headless-shell
```

## Поток использования

1. Регистрация / вход.
2. **Создать топ**: название, схема (сравнительная сортировка / швейцарка / круговая),
   слепой режим (опц.), ZIP-архив с треками — аудио (mp3/m4a/flac/…) и/или видео
   (mp4/webm/mov, рекомендуется MP4 H.264+AAC), лимит 2 ГБ. Инструкция «Как
   подготовить архив» — прямо на форме.
3. **Сравнения 1-на-1**: прослушать/просмотреть A/B, выбрать лево / ничья / право.
   Видео-треки играют в видеоплеере; в слепом режиме скрываются и названия, и
   видеоряд (трек играет как аудио до «Показать названия»). Прогресс сохраняется.
4. **Итоговый топ**: выбрать размер top-N.
5. **Конструктор рендера**: единый пул медиа (картинки + видео; массовая загрузка
   drag&drop, поиск, фильтр по типу, «недавние», постеры для видео). На каждую
   позицию — визуал (картинка, видео из пула или собственный видеоряд видео-трека)
   с недеструктивной обрезкой 16:9; звук — от трека или от вставленного видео
   (полная подмена OST видеорядом); сдвиг старта видеоряда, короткое видео
   зацикливается. Фрагмент — ручной таймлайн или активный сниппет; живой
   предпросмотр.
6. **Рендер** → скачать видео.

## Тесты

```bash
npm test
```

Покрытие (142 теста):
- доменные движки турнира (merge / swiss / round-robin): завершаемость,
  возобновляемость, корректность ранжирования, тай-брейки, граничные случаи;
- RMS-выбор активного сниппета;
- расчёт плана видео (порядок, тайминги плашек/визуала, длительности);
- сборка плана рендера из конфига, кламп сегмента по длине источника звука;
- правила позиции «визуал × звук» (матрица картинка/видео/видеоряд-трека ×
  трек/видео), луп короткого видео, валидация сдвига старта;
- разбор имён/тегов при загрузке, определение типа файла (аудио/видео);
- валидация обрезки и отображение рамки в CSS (общий код превью и рендера);
- интеграционный тест полного потока на реальной БД (Prisma + движок + ранжирование
  + конфиг рендера);
- интеграционные тесты пула медиа на реальной БД (поиск/пагинация/недавние/фильтр
  по типу, загрузка видео с пробой длительности/звука и постером, переименование,
  удаление с освобождением позиций, назначение и обрезка, подмена звука,
  изоляция чужих данных);
- интеграционные тесты видео-сценариев: смешанный ZIP, беззвучное видео,
  превью-план (синхронный видеоряд, луп, оверлей картинкой).

Кроме того, вручную провалидированы (см. историю разработки):
- ffmpeg-пайплайн (декод/нарезка аудио и видео, постеры, тишина-фолбэк);
- полный HTTP E2E: логин → смешанный ZIP → сравнения → финал → конфиг рендера
  + превью + подмена/оверлей + негативные пробы;
- headless-рендер MP4 с видео-сегментами (кадры выходного файла проверены).

## Структура

```
src/
  lib/domain/        # чистая доменная логика (движки, ранжирование, RMS, план видео) + тесты
  lib/               # upload (zip/id3), audio (ffmpeg), storage, render-assemble, db, api
  server/            # сервисы (tournaments, render) — серверные, используют Prisma
  remotion/          # Remotion-композиция (TopVideo) — рендер и предпросмотр
  app/               # Next.js App Router: страницы + API-роуты
  integration/       # интеграционный тест на БД
prisma/schema.prisma # модель данных (обе фазы)
scripts/             # вспомогательные скрипты (e2e, очистка тестовых данных)
```

## Рендер видео

Рендер работает end-to-end (проверено: на выходе валидный MP4 H.264 1920×1080 @30fps).
Используется headless-режим `chrome-for-testing` с системным Chrome — путь задаётся
через `REMOTION_BROWSER_EXECUTABLE` (в `.env.example` указан `/usr/bin/google-chrome`).
Альтернатива — `npx remotion browser ensure` (скачает chrome-headless-shell). Детали:
[`.ai/research/remotion-headless-render.md`](.ai/research/remotion-headless-render.md).
