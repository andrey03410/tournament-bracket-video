# OST Top Builder — MVP

Веб-приложение: строит **топы саундтреков (OST)** методом попарных сравнений
(турнирная сетка), затем рендерит видео-«топ». Для авторизованных пользователей,
с сохранением турниров и видео в личном кабинете.

Спецификации и план — в [`.ai/`](.ai/). Видение: [`.ai/specs/00-vision.md`](.ai/specs/00-vision.md).

## Стек

- **Next.js 14** (App Router, React 18) — фронт + API.
- **Prisma + SQLite** (MVP; продакшн-таргет Postgres — смена `provider` в схеме).
- **Auth.js (next-auth v5)** — email + пароль.
- **Remotion** — рендер видео (16:9, 1080p).
- **ffmpeg-static** — декод/нарезка аудио, RMS-анализ активного сниппета.
- **Vitest** — тесты.

## Быстрый старт

```bash
npm install
cp .env.example .env          # при необходимости отредактируйте AUTH_SECRET
npx prisma generate
npx prisma db push            # создаёт SQLite-схему (prisma/dev.db)
npm run dev                   # http://localhost:3000
```

Для рендера видео (один раз, в окружении с доступом в сеть):

```bash
npx remotion browser ensure   # скачивает chrome-headless-shell
# или укажите путь к chrome-headless-shell:
# REMOTION_BROWSER_EXECUTABLE=/path/to/chrome-headless-shell
```

## Поток использования

1. Регистрация / вход.
2. **Создать топ**: название, схема (сравнительная сортировка / швейцарка / круговая),
   слепой режим (опц.), ZIP-архив с OST.
3. **Сравнения 1-на-1**: прослушать A/B, выбрать лево / ничья / право. Прогресс
   сохраняется — можно прерваться и вернуться.
4. **Итоговый топ**: выбрать размер top-N.
5. **Конструктор рендера**: на каждый OST — арт (загрузка/переиспользование),
   фрагмент (ручной таймлайн или активный сниппет), длительность; живой предпросмотр.
6. **Рендер** → скачать видео.

## Тесты

```bash
npm test
```

Покрытие (59 тестов):
- доменные движки турнира (merge / swiss / round-robin): завершаемость,
  возобновляемость, корректность ранжирования, тай-брейки, граничные случаи;
- RMS-выбор активного сниппета;
- расчёт плана видео (порядок, тайминги плашек/арта, длительности);
- сборка плана рендера из конфига;
- разбор имён/тегов при загрузке;
- интеграционный тест полного потока на реальной БД (Prisma + движок + ранжирование
  + конфиг рендера).

Кроме того, вручную провалидированы (см. историю разработки):
- ffmpeg-пайплайн (декод/нарезка) на `ffmpeg-static`;
- полный HTTP E2E: логин → загрузка ZIP → сравнения → финал → конфиг рендера + превью.

## Структура

```
src/
  lib/domain/        # чистая доменная логика (движки, ранжирование, RMS, план видео) + тесты
  lib/               # upload (zip/id3), audio (ffmpeg), storage, render-assemble, db, api
  server/            # сервисы (tournaments, render) — серверные, используют Prisma
  remotion/          # Remotion-композиция (TopVideo) — рендер и предпросмотр
  app/               # Next.js App Router: страницы + API-роуты
  integration/       # интеграционный тест на БД
prisma/schema.prisma # модель данных (обе фазы)
scripts/             # вспомогательные скрипты (e2e, очистка тестовых данных)
```

## Рендер видео

Рендер работает end-to-end (проверено: на выходе валидный MP4 H.264 1920×1080 @30fps).
Используется headless-режим `chrome-for-testing` с системным Chrome — путь задаётся
через `REMOTION_BROWSER_EXECUTABLE` (в `.env.example` указан `/usr/bin/google-chrome`).
Альтернатива — `npx remotion browser ensure` (скачает chrome-headless-shell). Детали:
[`.ai/research/remotion-headless-render.md`](.ai/research/remotion-headless-render.md).
