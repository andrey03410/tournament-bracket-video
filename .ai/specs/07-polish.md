# Спецификация 07 — Доработки: окружение, фрагмент-превью, плейлист, фиксы рендера

Статус: согласовано с владельцем продукта (2026-07-13), реализуется в фазе 7.

## Согласованные решения

| Вопрос                     | Решение                                                          |
|----------------------------|------------------------------------------------------------------|
| Форма фрагмент-превью      | Встроенный плеер источника + «Старт отсюда» + «▶ Фрагмент» с автостопом |
| Охват фрагмент-превью      | Позиции топа (турнирного и ручного) + видео-плитки пикера        |
| Плейлист фоновой музыки    | На уровне проекта, играет сквозь всё видео; раунд-оверрайд остаётся (плейлист на нём молчит, но «идёт» — возобновляется с середины) |
| Переходы плейлиста         | Кроссфейд ~1 с между треками и на зацикливании                   |

## 1. Требования к окружению (README)

Раздел «Требования»: Node.js ≥ 18.17 (рекомендуется 20 LTS), npm; браузер
Chrome/Chromium для рендера (путь в `REMOTION_BROWSER_EXECUTABLE`); ffmpeg и
SQLite не ставятся — идут в комплекте (`ffmpeg-static`, встроенный SQLite
Prisma). Всё остальное — `npm install`.

## 2. Браузер для рендера

- `.env.example`: развёрнутый комментарий — зачем нужен браузер, что будет
  без него (Remotion попытается скачать chrome-headless-shell из сети и в
  оффлайне упадёт), как проверить путь.
- README: то же в разделе «Рендер видео».
- Джоба: если рендер упал по причине браузера (сообщение содержит
  browser/chrome/executable), в `job.error` добавляется подсказка про
  `REMOTION_BROWSER_EXECUTABLE`.

## 3. Фрагмент-превью

Компонент `FragmentPreview` (клиентский): нативный `<audio>`/`<video>` плеер
источника с контролами, текущим временем и кнопками:

- **«Старт отсюда»** — записать текущую позицию плеера в поле старта;
- **«▶ Фрагмент»** — проиграть ровно выбранный кусок (seek на старт,
  автостоп по концу фрагмента);
- индикатор выбранного окна «старт — конец».

Интеграция:
- Конструктор топа: на позиции, раскрывается кнопкой «🎧 Подобрать фрагмент».
  Источник — эффективный звук позиции (трек / аудио из пула / звук видео при
  подмене). «Старт отсюда» пишет `clipStartSec` (+ переключает режим на
  «Вручную», конец = старт + длина фрагмента, если не задан).
- Пикер: на видео-плитке, «Старт отсюда» пишет `startSec`, «▶ Фрагмент»
  играет окно `revealSec`.

## 4. Плейлист фоновой музыки (пикер)

- Схема: `PickerPlaylistItem { id, projectId, order, artId }` (аудио из пула).
- Семантика: плейлист — глобальная дорожка всего видео. Треки идут подряд с
  кроссфейдом 1 с, по исчерпании — луп (тоже с кроссфейдом). На раундах с
  собственной музыкой (`bgMusicArtId` раунда) плейлист приглушается до нуля,
  но таймлайн продолжает идти — после раунда музыка возвращается «с середины».
  Дакинг под звук плиток действует на активную дорожку (плейлист или
  оверрайд).
- План: `PickerPlan.music = { cues: [{ref, fromSec, durationSec, fadeInSec,
  fadeOutSec}], muteWindows, duckWindows }` — чистая функция `buildMusicCues`,
  юнит-тесты (нарезка по длительностям, кроссфейд-перекрытия, луп, обрезка по
  концу видео, mute-окна оверрайдов).
- Совместимость: старое поле `bgMusicArtId` проекта работает как плейлист из
  одного трека, пока плейлист пуст; первое сохранение плейлиста очищает его.
- UI: в настройках видео вместо одиночного чипа — редактор плейлиста
  (добавить из пула, порядок, удаление, суммарная длительность).
- Рендер: каждый уникальный трек плейлиста готовится один раз (AAC),
  cues ссылаются на подготовленные файлы.

## 5. Дефекты рендера (расследование + фикс)

Симптомы: (а) редкие чёрные кадры-«мерцания»; (б) местами звук обрывается
без затухания.

Гипотезы для проверки (по коду):
- (а) `Loop durationInFrames = Math.round(loopSec*fps)` может на кадр
  превышать реально доступные кадры пре-клипа (re-encode укорачивает файл на
  долю кадра) → чёрный кадр на границе лупа/хвосте сегмента. Фикс: floor с
  защитным кадром и пре-клип с запасом, где позволяет источник.
- (б) В композициях **нет audio-envelope вовсе** — `<Audio>` играет встык;
  «затухание» слышалось только когда трек сам утихал. Фикс: явный fade-in
  ~0.3 с и fade-out ~1 с (синхронно с визуальным фейдом) на сегментах топа;
  границы клипа зажать в пределах длительности источника.

Фиксы подтверждаются рендером: кадры на границах сегментов/лупов без чёрных
вспышек, WAV-хвост сегмента показывает спад амплитуды.

## Тесты

- Юнит: `buildMusicCues` (см. выше), envelope-математика сегмента (если
  выделится в чистую функцию).
- Интеграционные: CRUD плейлиста (только аудио, порядок, изоляция), фолбэк
  legacy `bgMusicArtId`, превью-план с `music.cues`/mute-окнами.
- Вживую: план плейлиста через HTTP, UI фрагмент-превью (кнопки реально
  двигают поля), рендер с проверкой кадров и звуковых хвостов.

## Вне скоупа

- Волноформа-таймлайн в фрагмент-превью; плейлисты на раундах; нормализация
  громкости.
