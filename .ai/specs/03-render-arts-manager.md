# Спека: менеджер артов, пикер и обрезка (доработка конструктора рендера)

Дата: 2026-07-10. Статус: согласовано, в работе.

## Мотивация

Сейчас в конструкторе рендера арты загружаются по одному файлу без имени, выбор
арта для позиции — ряд мини-кнопок всего пула под каждой позицией. При десятках и
сотнях картинок это неуправляемо. Обрезки нет: картинка всегда кадрируется
автоматически по центру (`objectFit: cover` на весь кадр 16:9).

## Решения (согласованы с продуктом)

1. **Кроп недеструктивный и привязан к позиции** (`RenderItem`), оригинал в пуле
   не меняется. Одна картинка может быть обрезана по-разному в разных позициях.
2. **Менеджер артов — полный**: мультизагрузка + drag&drop, удаление
   (с подтверждением и числом использований), переименование (метки).
3. **Пикер — модальная галерея**: поиск по метке, блок «Недавние», сетка превью
   с бесконечной подгрузкой, загрузка новой картинки прямо из пикера.
4. **Шаг кропа появляется сразу после выбора картинки**, его можно пропустить
   («Без обрезки» = авто-cover). Кроп можно переоткрыть и поправить позже.

## Модель данных

```prisma
model Art {
  // + новое поле:
  lastUsedAt DateTime?   // обновляется при назначении арта позиции; сортировка «Недавних»
}

model RenderItem {
  // + новые поля (нормализованный прямоугольник кропа, доли 0..1 от исходника):
  artCropX Float?
  artCropY Float?
  artCropW Float?
  artCropH Float?
}
```

- Прямоугольник кропа имеет аспект 16:9 **в пикселях исходника** (доли 0..1 сами
  по себе аспект не сохраняют — им и не нужно).
- Все четыре поля либо заданы, либо все `null` (= авто-cover). Валидация в API.
- При смене арта позиции кроп сбрасывается в `null`.

## API

| Метод | Роут | Изменение |
|---|---|---|
| GET | `/api/arts?q=&cursor=&limit=` | поиск по `label` (contains), cursor-пагинация по `createdAt desc, id`, `limit` по умолчанию 40 (max 100); в ответе `usageCount` (`_count.renderItems`) и `lastUsedAt` |
| GET | `/api/arts?recent=1` | топ-8 по `lastUsedAt desc` (только с ненулевым `lastUsedAt`) |
| POST | `/api/arts` | без изменений по контракту; `label` по умолчанию = имя файла без расширения. Мультизагрузка — клиент шлёт несколько запросов |
| PATCH | `/api/arts/[id]` | `{ label }` — переименование |
| DELETE | `/api/arts/[id]` | удаляет файл со стораджа и запись; `RenderItem.artId` освобождается существующим `onDelete: SetNull`; кроп-поля осиротевших позиций чистятся в том же запросе |
| PATCH | `/api/render-items/[id]` | дополнительно принимает `artCrop: {x,y,w,h} \| null`; при смене `artId` кроп сбрасывается и обновляется `Art.lastUsedAt` |

Все роуты — только для владельца (существующий `userOr401`).

## Рендер кропа

- Чистая функция `artCropStyle(crop | null)` → CSS-позиционирование
  (`position/width/height/left/top` в процентах внутри контейнера с
  `overflow: hidden`): `width = 100/w %`, `left = -x/w · 100 %`,
  `height = 100/h %`, `top = -y/h · 100 %`. `null` → текущий `objectFit: cover`.
- Кладётся в `src/remotion/crop.ts`, используется и в `TopVideo` (Player-превью и
  headless-рендер — один код), и в мини-превью арта у позиции в конструкторе.
- `VideoPlan`-сегмент получает опциональный `artCrop`; `video-plan.ts` и
  `render-assemble.ts` прокидывают его из `RenderItem`.

## UI (конструктор рендера)

Один модальный компонент `ArtGalleryModal` (новый файл рядом с
`RenderConstructor.tsx`), два режима:

- **manage** — открывается кнопкой «Менеджер артов» на панели: drag&drop-зона и
  выбор нескольких файлов, у карточки — переименование (инлайн) и удаление
  (подтверждение с числом использований).
- **pick** — открывается кнопкой у позиции: строка поиска (дебаунс 300 мс), ряд
  «Недавние», сетка «Все» с подгрузкой через IntersectionObserver, кнопка
  загрузки. Клик по карточке → шаг кропа.

Шаг кропа: `react-easy-crop` (aspect 16/9, зум-слайдер), кнопки «Применить»,
«Без обрезки», «Назад». Результат (`croppedAreaPixels` → нормализованные доли)
уходит в `PATCH /api/render-items/[id]`.

У позиции вместо ряда всех артов: превью текущего арта (с учётом кропа) и кнопки
«Выбрать/Заменить», «Обрезать» (переоткрывает кроп с текущими значениями),
«Убрать».

Панель «Загрузка арта» заменяется кнопкой «Менеджер артов».

## Тесты

- `crop.ts`: прямоугольник → CSS (центр, края, зум, null).
- `video-plan`: прокидывание `artCrop` в сегменты.
- `render-assemble`: конфиг с кропом → план с кропом; сброс при несогласованных
  полях не пропускается валидацией API (юнит на нормализацию входа).
- API-валидация `artCrop` (границы 0..1, все-или-ничего) — юнит на общий хелпер.
- UI проверяется вручную через запущенное приложение (drag&drop, поиск,
  подгрузка, кроп → превью → рендер).

## Вне скоупа

- Запекание кропа в файл (sharp/ffmpeg) — отклонено: лишняя зависимость,
  кроп нельзя поправить.
- Теги/папки/коллекции артов, дедупликация по хешу.
- Автоподбор арта по названию трека.
