# Спека 04 — Поддержка видео (турниры, пул медиа, подмена и оверлей в рендере)

Статус: согласована с пользователем 2026-07-10 (вопрос-ответ, см. решения ниже).

## Цель

Видео становится полноправным медиа в продукте, в двух ролях:

1. **Видео-трек** — участник турнира. Грузится в ZIP вместе с аудио (или без него),
   сравнивается в плеере, попадает в топ и рендер со своим видеорядом и звуком.
   Поддерживается смешанный турнир (аудио + видео вперемешку).
2. **Видео из пула** — грузится в менеджер медиа (бывший «менеджер артов»),
   вставляется на позицию рендера как видеоряд (например, опенинг поверх OST).

На этапе рендера у каждой позиции независимо настраиваются **визуал** и **звук**,
что даёт подмену OST → видео, «наоборот» (видео-позиция как классическая
OST-позиция с картинкой) и перекрытие видеоряда картинкой.

## Согласованные решения

| Вопрос | Решение |
|---|---|
| Звук позиции с видео из пула | Явный переключатель на позиции: «звук трека» / «звук видео». Видео без аудиодорожки → вариант «звук видео» недоступен |
| Видео короче сегмента (визуал) | Луп до конца сегмента |
| Форматы | `.mp4`/`.webm`/`.mov` как есть, без транскода; остальные — отказ с понятной ошибкой |
| Слепой режим | Скрывает и видеоряд: видео-трек играет как аудио под заглушкой 🎧, кнопка «Показать» раскрывает (как сейчас с названиями) |
| Кроп видео | Та же рамка 16:9 (сдвиг/зум), что и для картинок — единый UX и единая математика `artCropStyle` |
| Инструкции | Инлайн: раскрывающийся блок «Как подготовить архив» на форме создания + подсказки в конструкторе. Отдельной страницы нет |

## Модель данных (Prisma)

- `Track.kind: String @default("audio")` — `"audio" | "video"`.
- `Art` (понятийно «медиа», имя модели не меняем ради совместимости):
  - `kind: String @default("image")` — `"image" | "video"`;
  - `durationSec: Float?` — для видео;
  - `hasAudio: Boolean @default(false)` — есть ли аудиодорожка (для видео);
  - `posterPath: String?` — кадр-постер (jpg), генерируется ffmpeg при загрузке видео.
- `RenderItem`:
  - `audioSource: String @default("track")` — `"track" | "media"`; `"media"`
    допустим только когда назначено видео из пула с `hasAudio`;
  - `mediaStartSec: Float?` — сдвиг старта видеоряда, когда видео — только визуал
    (звук от трека); по умолчанию 0.

Существующие поля переиспользуются: `artId` теперь может указывать на медиа любого
типа; кроп-колонки (`artCropX/Y/W/H`) применяются и к видео.

## Правила позиции (доменная логика)

Визуал позиции (приоритет сверху вниз):

1. назначено медиа из пула (`artId`) → показываем его (картинка или видео);
2. иначе, если трек — видео → показываем собственный видеоряд трека;
3. иначе → заглушка `#N`.

Звук позиции:

- `audioSource = "track"` → звук трека (для видео-трека — его собственная
  аудиодорожка), клип-механика без изменений (manual / active_snippet / full,
  RMS-анализ работает по аудиодорожке файла);
- `audioSource = "media"` → звук назначенного видео из пула; клип-поля
  (`clipMode/clipStartSec/clipEndSec/snippetLenSec`) применяются к этому видео,
  длина фрагмента дополнительно ограничивается длиной видео.

Видеоряд:

- если звук идёт из того же видео → видеоряд синхронен звуку (тот же фрагмент);
- если видео — только визуал → старт с `mediaStartSec` (по умолчанию 0),
  при нехватке длины — **луп** до конца сегмента;
- кроп-рамка применяется к видеоряду так же, как к картинке (`artCropStyle`).

Инварианты и сбросы:

- смена `artId` → сброс кропа, `mediaStartSec` и `audioSource → "track"`
  (если новое медиа — не видео со звуком);
- `audioSource = "media"` без назначенного видео со звуком → ошибка `NO_MEDIA_AUDIO`;
- смена `audioSource`/клип-полей → сброс `resolvedStartSec`;
- удаление медиа из пула → позиции освобождаются: кроп, `mediaStartSec`,
  `audioSource` возвращаются к дефолтам (расширение текущей механики).

## Загрузка

- ZIP: к `AUDIO_EXT` добавляется `VIDEO_EXT = [.mp4, .webm, .mov]`. Тип трека —
  по расширению. Смешанный архив = смешанный турнир, без отдельного режима.
- Метаданные видео: длительность/наличие аудио — через ffmpeg-пробу
  (парсинг stderr `ffmpeg -i`, как `probeDurationSec`); название — из имени файла.
- Пул: те же расширения в менеджере; для видео при загрузке генерируются
  постер (первый кадр, jpg) и длительность/`hasAudio`.
- Лимит: явная проверка размера тела запроса (2 ГБ), при превышении — 413 с
  человеческим сообщением (сейчас большой архив падает молча).

## Сравнения

- Видео-трек: `<video>`-плеер (letterbox в боксе выбора). Пара «аудио vs видео» —
  каждый со своим плеером.
- Автопауза: старт одного плеера ставит второй на паузу (и для аудио тоже).
- Слепой режим: у видео-треков рисуем `<audio>` на тот же файл (браузер играет
  аудиодорожку mp4/webm), картинка скрыта заглушкой 🎧; «Показать названия»
  раскрывает и названия, и видеоряд.
- Отдача файла: текущий роут `/api/tracks/[id]/audio` уже отдаёт 206 Range —
  переиспользуем для видео (корректный Content-Type по расширению).

## Конструктор рендера

- Менеджер медиа: фильтр «Все / Картинки / Видео», карточка видео — постер +
  бейдж длительности (𝍪 0:47) + признак «без звука», ховер ничего не играет.
- Пикер по позиции: те же фильтры; после выбора видео открывается кроп-шаг
  (рамка поверх видео), как у картинок — можно пропустить.
- Позиция:
  - превью-миниатюра: постер видео (с кропом) вместо тега `<video>`;
  - переключатель звука «Трек / Видео» — виден только когда назначено видео
    со звуком;
  - поле «Старт видеоряда, с» — видно только когда видео является визуалом,
    а звук идёт от трека;
  - у видео-трека кнопка «Убрать» возвращает собственный видеоряд (не заглушку).
- Подсказки: короткий hint-текст у переключателя звука и в пикере
  («видео короче фрагмента будет зациклено»).

## Рендер и превью

- План (`video-plan`): сегмент вместо `artPath/artCrop` несёт объект
  `visual: { kind: "image" | "video" | "none", path, crop, startSec, loopSec }`
  и, как раньше, `audioPath/clipStartSec`. Превью и headless-рендер строятся
  из одного плана.
- `TopVideo`: видео-визуал — `<OffthreadVideo>` (в Player автоматически
  рендерится как `<Video>`), обёрнутый в `<Loop durationInFrames=loopSec*fps>`
  при нехватке длины; `muted` всегда (звук в композиции идёт отдельным
  `<Audio>`, как сейчас).
- Пайплайн рендера: как аудио пре-клипается в `.aac`, видео пре-клипается
  ffmpeg-ом в `.mp4` (H.264/AAC, точный seek с перекодом); при `audioSource="media"`
  звук извлекается из того же видео. Всё складывается в per-job `public/`.
- Видео не 16:9 — cover по центру по умолчанию, кроп-рамкой можно сдвинуть.
- Нормализация громкости OST vs видео — вне скоупа, упоминается в инструкциях.

## Инструкции (продуктовые тексты)

- Форма создания топа, раскрывающийся блок «Как подготовить архив»:
  поддерживаемые форматы (аудио: mp3/m4a/flac/…, видео: mp4/webm/mov,
  рекомендация — MP4 H.264 + AAC), лимит 2 ГБ, названия из тегов/имён файлов,
  смешанные архивы допустимы, слепой режим скрывает и видеоряд.
- Конструктор: подсказки у переключателя звука и про луп короткого видео.

## Тесты (все сценарии, включая краевые)

Домен (юниты):

- определение типа по расширению (все ext, регистр, `__MACOSX`, дотфайлы);
- матрица «визуал × звук» позиции: 6 комбинаций из раздела «Правила позиции»;
- клип при `audioSource="media"`: клип-поля применяются к видео, кламп по его
  длине (manual за пределами длины, snippet длиннее видео, full);
- луп: `loopSec` в сегменте при видео короче сегмента; ровно равное — без лупа;
- `mediaStartSec`: отрицательный/за пределами длины → валидация;
- кроп видео: та же математика, сброс при смене медиа;
- план: сегменты смешанного топа (image / video / trackVideo / placeholder).

Сервисы (интеграционные, реальная БД):

- загрузка видео в пул: kind/duration/hasAudio/poster записаны, файл и постер
  на диске; беззвучное видео → `hasAudio=false`;
- загрузка `.mkv`/`.avi` → `BAD_EXT`;
- фильтр пула по kind + поиск + пагинация;
- назначение видео на позицию: кроп/старт/звук по умолчанию; переключение
  `audioSource` на «media» у видео со звуком — ок, у беззвучного/у картинки —
  `NO_MEDIA_AUDIO`; сброс `resolvedStartSec`;
- смена медиа → сброс кропа/`mediaStartSec`/`audioSource`;
- удаление видео из пула → позиции освобождены, дефолты восстановлены;
- смешанный ZIP → треки с корректными kind; турнир из одних видео; видео без
  аудиодорожки как трек (сравнимо, RMS не падает — старт 0);
- чужие данные (медиа/позиции) недоступны.

Вживую (verify-скилл): полный UI-сценарий на смешанном турнире + негативные
HTTP-пробы (мусорные `audioSource`/`mediaStartSec`, `audioSource=media` на
картинке, 413 на переросшем лимите — синтетически).

## Вне скоупа

- Транскод произвольных форматов при загрузке.
- Нормализация громкости между OST и звуком видео.
- Ховер-превью видео в галерее.
- Постобработка видеоряда (фильтры, скорость).
