# Фаза 18 — множественные сравнения (ранжирование групп)

Спека: [`../specs/18-group-ranking.md`](../specs/18-group-ranking.md).
Каждая задача закрывается тестами, красный прогон — до реализации.

- [x] **1. Доменный разбор ответа группы.** `lib/domain/group-answer.ts`:
  ранжированный префикс + «остальные равны» → список пар `(a, b, result)`;
  целевое число сравнений на трек `ceil(log₂ N)`; оценка экранов по схеме и k;
  зажим `groupSize` в 2..7 и по числу треков. Юнит-тесты, включая пустой
  префикс, полный префикс и группу из двух.

- [x] **2. Определённость порядка.** `lib/domain/order-coverage.ts`:
  транзитивное замыкание на битсетах → доля расставленных пар, число
  противоречивых пар, число треков в циклах. Юнит-тесты на цепочку, цикл и
  ничьи (ничья порядок не задаёт).

- [x] **3. Движки.** `nextQuestion(items, log, groupSize)` в интерфейсе,
  `nextPair` — обёртка при k=2. Швейцарка строится от состояния лога, круговая
  жадно набирает группу, merge объявляет `maxGroupSize = 2`. Тесты: все краевые
  случаи из спеки, симуляция до завершения при k=2..5, неизменность поведения
  при k=2.

- [x] **4. Модель данных.** `ComparisonBatch`, `Comparison.batchId`,
  `Tournament.groupSize`; `db push` + `generate`. Проверка дрейфа схемы.

- [x] **5. Сервис и API.** `recordGroupAnswer` со сверкой присланной группы с
  той, которую движок действительно спрашивает; `undoLastBatch`; `groupSize` в
  PATCH турнира; `/next` отдаёт вопрос, план, экраны и определённость;
  завершённый турнир не открывается заново. Интеграционные тесты на живой БД.

- [x] **6. Экран сравнения.** Клики по порядку с ранним стопом, выбор размера
  прямо на экране, отмена последнего ответа, индикатор определённости,
  «Ещё раунд» / «Завершить»; при k=2 — сегодняшняя раскладка. Форма создания
  получает поле размера и живую оценку экранов.

- [x] **7. Проверка и документация.** Полный `npm test` при остановленном dev,
  headless-прогон группового турнира от создания до топа, прогон реального
  лога на 201 трек через новый движок на предмет противоречий; README,
  CLAUDE.md, статус спеки, рецепт в `.claude/skills/verify/`.
