# Фаза 8 — Импорт по ссылке (yt-dlp): декомпозиция

Спека: [`../specs/08-url-import.md`](../specs/08-url-import.md).

## Задачи

- [ ] T8.1 `src/lib/ytdlp.ts`: ensure/обновление бинарника (env → storage/bin
      → GitHub-релиз), probe `-J`, downloadMedia с прогрессом и max-filesize,
      детект поломки экстрактора. Юнит-тесты чистых частей.
- [ ] T8.2 Схема `DownloadJob` + `createArtFromFile` в arts.ts (зачисление
      файла в пул без буферизации, транзакционная квота).
- [ ] T8.3 Сервис downloads (лимит 2 активных, фоновый запуск, ретрай с -U,
      отмена kill-ом, финальная квота) + роуты `/api/downloads*`.
      Интеграционные тесты на локальном HTTP-источнике.
- [ ] T8.4 UI менеджера медиа: поле ссылки, режим/качество, список загрузок
      (прогресс/отмена/ошибки), автообновление пула.
- [ ] T8.5 Верификация вживую (реальный YouTube: видео 480p + аудио; негативные
      пробы; UI-прогон) + README/CLAUDE.md/verify + коммиты.

## Готово, когда

Ссылка на YouTube-ролик превращается в карточку пула (видео или аудио) без
удержания вкладки открытой, прогресс виден, отмена работает, квоты и роли
соблюдены, старый системный yt-dlp не мешает (работает свежий бинарник).
