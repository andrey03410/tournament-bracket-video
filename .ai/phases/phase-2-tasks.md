# Фаза 2 — Декомпозиция на задачи

Спека: [`../specs/02-phase-render.md`](../specs/02-phase-render.md).

## MVP-решения по стеку

- Рендер: **Remotion** (16:9, 1920x1080). Async-задача (job) с прогрессом.
- Аудио: **ffmpeg-static** (системного ffmpeg нет) — декод в PCM для RMS-анализа и
  нарезка фрагмента с фейдами.
- Активный сниппет: RMS-анализ по окнам, выбор окна с макс. средней энергией.

## Задачи

- [x] T2.1 Модели Фазы 2: RenderConfig, TrackRenderItem, Art, RenderJob (в схеме Prisma).
- [x] T2.2 Доменный RMS-анализ: из массива сэмплов выбрать окно длины L с макс. ср. энергией.
- [x] T2.3 Аудио-сервис: декод через ffmpeg-static, нарезка фрагмента, fade in/out.
- [x] T2.4 Remotion-композиция: интро → элементы (арт fade, плашка `N - Назв (Источник)`
  через 1с, держится 5с) → пауза 1с с затуханием между OST → аутро. Обратный порядок N→1.
- [x] T2.5 Конструктор (UI): на каждый OST — арт (загрузка/переиспользование),
  длительность (глобал+override), фрагмент (ручной таймлайн / активный сниппет).
- [x] T2.6 Живой предпросмотр через Remotion Player.
- [x] T2.7 Async рендер-job: запуск, прогресс, сохранение видео, скачивание, история.
- [x] T2.8 Unit-тесты: RMS-выбор окна, расчёт тайминга композиции, сборка плана видео.

## Готово, когда

По завершённому топу пользователь настраивает оформление, видит предпросмотр,
запускает рендер, получает скачиваемое видео; конфиг сохраняется и ре-рендерится.
Доменная логика (RMS, тайминг) зелёная по тестам.

## Примечание по рендеру

Цепочка рендера (нарезка аудио через ffmpeg-static → сборка Remotion-бандла → джоба
с прогрессом → скачивание) реализована и провалидирована. Сам шаг headless-рендера
требует `chrome-headless-shell` (`npx remotion browser ensure`); путь к браузеру
настраивается через `REMOTION_BROWSER_EXECUTABLE`. Детали:
[`../research/remotion-headless-render.md`](../research/remotion-headless-render.md).
