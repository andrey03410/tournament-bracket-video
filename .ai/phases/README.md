# Фазы разработки

Проект делится на 2 основные фазы. См. общее видение в
[`.ai/specs/00-vision.md`](../specs/00-vision.md).

| Фаза | Название           | Цель                                                                 | Статус       |
|------|--------------------|----------------------------------------------------------------------|--------------|
| 1    | Турнирная сетка    | Загрузка OST, выбор схемы, попарные сравнения, итоговый топ, ЛК       | 🟢 спека готова |
| 2    | Рендер видео       | Конструктор оформления топа + рендер видео + скачивание              | 🟢 спека готова |

Детальные спеки фаз появляются в `.ai/specs/` после прохождения ревью user story:

- Фаза 1 — [`../specs/01-phase-tournament.md`](../specs/01-phase-tournament.md)
- Фаза 2 — [`../specs/02-phase-render.md`](../specs/02-phase-render.md)
